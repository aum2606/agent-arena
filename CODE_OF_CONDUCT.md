# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, give and accept feedback graciously, and do not harass anyone.
Harassment, personal attacks, discriminatory language and publishing others' private information are not
acceptable in issues, pull requests, discussions or any other project space.

Maintainers may edit or remove comments, commits and issues that break these rules, and may ban
contributors who do so repeatedly.

To report a problem, use GitHub's private reporting on the repository (**Security → Report a
vulnerability** works for this too) or contact the maintainer, [@aum2606](https://github.com/aum2606),
directly. Reports are handled privately.
